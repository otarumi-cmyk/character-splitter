転職エージェントおすすめデモ
DEMO
デモ用の想定条件

このページは、年収診断の本番結果画面で表示される「あなたにおすすめの転職エージェント」の イメージを確認するための簡易デモです。
条件とエージェント候補はサンプルデータをもとにしています。

リクナビ／メルセンヌの実ロゴを見る：
demo-assets/rikunabi-next.png と demo-assets/mersenne-sales.png を配置し、 http://127.0.0.1:8080/... で開いてください（詳細は demo-assets/README.md）。

ローカルで見る
このHTMLをダブルクリックで開くだけでOK（外部フォント・画像なし）。
フォルダで python3 -m http.server 8080 実行後、 http://127.0.0.1:8080/salary-agent-recommendation-demo.html でも開けます。

あなたにおすすめの転職エージェント

    条件にぴったり合うエージェントが見つかりませんでした。条件を少し広げて再度お試しください。
