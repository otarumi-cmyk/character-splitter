# 年収診断フロー用画像アセット

LP・各ステップで使う画像をまとめています。**`/var/folders/.../T/clipimage_*.png` のような一時パスは消えると表示できなくなる**ため、プロジェクト内のこのフォルダに置き、HTML からは相対パス `salary-diagnosis-assets/ファイル名` で参照します。

| ファイル | 用途 |
|----------|------|
| `header-logo.png` | ヘッダー（よりそい転職ロゴ等） |
| `staff-female.png` | LP 女性スタッフ |
| `staff-male.png` | LP 男性スタッフ |
| `ai-badge.png` | 「AIによって〜」のバッジ画像 |
| `guide-pointer.png` | アコーディオン誘導カーソル／指アイコン |

## 差し替え

同じファイル名で上書きすれば、そのまま全ページに反映されます。サーバーに上げるときは **このフォルダごと** アップロードしてください。
