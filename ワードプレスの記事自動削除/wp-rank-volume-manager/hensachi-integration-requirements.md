# 年収診断 × 年収偏差値診断 結合要件定義

## 1. 対象ファイル・範囲

- **対象画面**: `salary-diagnosis-result.html`（現在の年収診断・結果画面）
- **参照元ロジック**: `Downloads/年収診断_デザイン修正版.html` 内の
  - `.salary-widget` 配下の年収偏差値診断 UI
  - 内部 `<script>` の年収偏差値計算ロジック & 統計データ一式
- **変更してよい範囲**:
  - `salary-diagnosis-result.html` の「同じ条件の年収分布」カードの **カード本体の中身のみ**
  - 同ファイル末尾 `<script>` 内へのロジック追加・改修
- **絶対に消してはいけないもの**:
  - 「診断結果」カード（適正年収）
  - 「AIキャリアアドバイザーからのアドバイス」カード
  - 「おすすめの求人情報」カード
  - ページ下部リンク「もう一度年収診断をする」
  - 上記カード内テキスト（偏差値統合とは別物として維持）

---

## 2. ゴール

- 現在の結果画面 2枚目のカード（「同じ条件の年収分布」）を、
  - `年収診断_デザイン修正版.html` に入っている **年収偏差値ロジック**と
  - 既存の診断ステップで取得しているユーザーデータ
  を使って、
  - **「自分の年収が平均と比べてどの位置か」が分かる偏差値カード**に置き換える。

- 上記に加えて、同じカード内に **「平均との差をビジュアルで示す棒グラフ（分布＋自分の位置）」** を表示する。

- 「診断結果」「アドバイス」「求人情報」カードはそのまま残し、
  - 2枚目カードの中身だけを差し替える。

---

## 3. データ連携要件

### 3-1. 年収（現在の年収）

- すでにランディングページでレンジ選択 → `localStorage` 保存済:
  - `diagnosisSalary` … 基準となる**現年収（円）**（レンジの代表値）
- 結果画面の「適正年収」はすでに以下で計算済み:
  - 適正年収 = `diagnosisSalary + 1,000,000`
- **偏差値ロジック側での扱い**:
  - `baseSalary = diagnosisSalary`
  - 入力単位は「万円」を想定:
    - `incomeK = baseSalary / 10000` を偏差値ロジックの「年収(万円)」として使う。

### 3-2. 年齢

- `salary-diagnosis-step.html` で取得している年齢レンジ:
  - name: `age`
  - 値:
    - `〜24歳`
    - `25〜29歳`
    - `30〜34歳`
    - `35〜39歳`
    - `40〜49歳`
    - `50歳〜`

- **結果画面での変換仕様**（偏差値ロジックに渡す数値年齢）:
  - `〜24歳` → 22
  - `25〜29歳` → 27
  - `30〜34歳` → 32
  - `35〜39歳` → 37
  - `40〜49歳` → 45
  - `50歳〜` → 55

- 上記マップで数値年齢が出せなかった場合:
  - 偏差値は計算せず、`--` 表示（フォールバック扱い）。

### 3-3. 業界（任意）

- 偏差値ロジック側には `industrySalary` と `data-industry` セレクトが存在。
- 既存の診断フローは「職種」はあるが「業界」は明確には無い。

- **必須要件（第一段階）**:
  - 業界は **未指定を許容**。
  - 業界未選択時は「業界別の偏差値」は `--` か「業界未指定のため表示されません」とする。

- **発展案（任意）**:
  - `diagnosisCurrentJob` / `diagnosisDesiredJob` を簡易マップで `industrySalary` のキーに変換してもよい（別途テーブルを持つ）。

## 4. UI 要件

### 4-1. カード構造

- 該当カード（2枚目）は引き続き `<section class="card">` を利用。
- 見出しテキストは必要に応じて変更可:
  - 例: `同じ条件の年収分布（年収偏差値）`
- カード内のレイアウトは既存デザイン（白カード / タイトル行 / 本文エリア / 小さめ注記）に合わせる。

### 4-2. 表示内容

- **メイン偏差値**:
  - ラベル: 「年収偏差値」
  - 数値: 小数1桁（例: `52.3`）
  - 色: スコア ≥ 50 → ブルー、＜50 → レッド

- **サブ偏差値**（必要なもののみ採用）:
  - 男性での偏差値
  - 女性での偏差値
  - 大学卒での偏差値
  - 大企業での偏差値
  - 業界別の偏差値（業界が決まる場合のみ）

- 各偏差値の下に簡単な文章（`sw-detail` 相当）を表示:
  - 例: 「同年代男性の平均年収と比べたときの位置です。」など。

- 旧ダミー棒グラフ:
  - `dist-bar` 群は削除してよい。
  - `dist-legend` のテキストは、偏差値の解説文に差し替える。

### 4-3. 棒グラフ（自分の位置）の見た目

- カード構成は **2段構成** とする:
  - 上段: 「あなたの年収偏差値」＋数値表示（既に実装済み）
  - 下段: 「年収分布ヒストグラム＋自分のレンジだけ色を変えた棒グラフ」

- **縦棒ヒストグラム（分布）**
  - **おおよそ 100 万円刻みで 10 本の縦棒**を並べる:
    - 〜100万円
    - 100〜200万円
    - 200〜300万円
    - 300〜400万円
    - 400〜500万円
    - 500〜600万円
    - 600〜700万円
    - 700〜800万円
    - 800〜900万円
    - 900万円〜（それ以上をすべて集約）
  - 各棒の高さは、対応する所得階級（`incomeBounds` と `ageData`）に属する人数を合計し、**「本グラフ内で最も人数が多いレンジを100％とした相対値」**として決める。
  - **ユーザーの年収が属するレンジの棒だけオレンジ（`highlight`）で表示**し、それ以外は淡いブルー〜グレー系で表示。
  - グラフ下部に、上記レンジをそのまま X 軸ラベルとして表示する。

- **水平バー＋ポインタ（偏差値の位置）**
  - 既存の横長バーを維持し、偏差値 0〜100 を横軸にマッピングして、
    - オレンジの塗りつぶし（左からスコアまで）
    - 縦のポインタ線（現在位置）
  - ラベルはバー下に「低い / 平均 / 高い」の 3 つを配置。

- デザイン統一:
  - 棒・バーのカラーはページ全体に合わせた **オレンジ（強調）＋青/グレー（その他）** ベース。
  - 背景は既存カードと同じ白、余白やフォントサイズも他カードと違和感がないように調整する。
  - スマホではヒストグラムは高さ 80〜120px 程度のコンパクトなものにし、PC ではやや縦長でもよい。
  - グラフ直下に短い注記:
    - 例: 「※グラフは統計データをもとにした概算です。」など。

## 5. ロジック統合要件

### 5-1. 取り込むコード

`年収診断_デザイン修正版.html` から、以下を `salary-diagnosis-result.html` の `<script>` 内に移植・再利用する:

- データ定義:
  - `incomeBounds`
  - `ageData` / `ageGroups`
  - `avgMonthlyByAgeGenderYen`
  - `avgMonthlyUnivByAgeYen`
  - `avgMonthlyBigCompanyByAgeYen`
  - `industrySalary`
- 補助関数:
  - `getMonthlyMeanYen(age, gender)`
  - `getInterpolatedData(age)`
  - `getUnivMonthlyMeanYen(age)`
  - `getBigCompanyMonthlyMeanYen(age)`
  - `getIndustryMonthlyMeanK(age, industry)`
  - `setScore(el, score)`（表示＋色付け）

**除外してよいもの:**

- `<meta name="viewport">` を追加する処理（結果ページ側では不要）
- `.salary-widget` 固有の DOM 構造に依存した `querySelector` 群（結果ページ用の DOM に合わせて書き直す）

### 5-2. 計算フロー

1. 結果ページ初期化時（既存 IIFE 内）で以下を行う:
   - `diagnosisSalary` を `localStorage` から取得。
   - 将来的に `diagnosisAgeRange`（年齢レンジ文字列）も `localStorage` から取得する前提。
2. 年齢レンジ文字列 → 数値年齢に変換（3-2のテーブル）。
3. `incomeK = diagnosisSalary / 10000` を算出。
4. 偏差値ロジックを呼び出し、各スコアを DOM に反映。
5. 年齢か年収が欠けている場合:
   - 計算をスキップし、数値部分は `--` 表示。

---

## 6. フォールバック仕様

- `diagnosisSalary` が存在しない / 0 以下:
  - 適正年収カードは既存のデフォルト動作（例: 800万円）を維持。
  - 偏差値カードは `--` 表示＋「条件不足のため偏差値は表示できません」のような注記を出す。

- 年齢レンジが取得できない:
  - 同じく偏差値はすべて `--`、カード自体は残す。

---

## 7. 既存コンテンツ保護ルール

- 以下は偏差値統合の際にも **変更しない／削除しない**:
  - 「診断結果」カードの構造と文言（必要なら適正年収の数値だけ動的に変更）
  - 「AIキャリアアドバイザーからのアドバイス」カード一式
  - 「おすすめの求人情報」カード一式
  - 下部リンク「もう一度年収診断をする」
  - ページ全体レイアウト（`page-wrap` や背景色など）

## 8. 実装ステップ（開発者向けメモ）

1. `年収診断_デザイン修正版.html` から統計データと関数を切り出し、`salary-diagnosis-result.html` の `<script>` に移植。
2. 「同じ条件の年収分布」カードの中身を、新しい偏差値表示用の DOM に差し替える。
3. `diagnosisSalary`・（将来）`diagnosisAgeRange` を `localStorage` から取得し、数値年齢＋年収(万円)に変換する処理を追加。
4. 偏差値スコアを計算して画面に反映。
5. PC/スマホ両方でレイアウト崩れがないか、既存3カードが壊れていないか確認する。
