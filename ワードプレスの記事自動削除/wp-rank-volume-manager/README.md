# wp-rank-volume-manager

## Overview
The WP Rank Volume Manager is a WordPress plugin designed to automate the management of article visibility based on search rankings and keyword volumes. It helps users identify underperforming articles and manage their publication status efficiently.

## Features
- Automatically unpublishes articles based on user-defined criteria (search ranking and keyword volume).
- Provides a dashboard for monitoring article performance.
- Allows for easy restoration of unpublished articles.
- Supports CSV import for article data management.
- Customizable settings for thresholds and evaluation logic.

## Installation
1. Download the plugin files.
2. Upload the `wp-rank-volume-manager` folder to the `/wp-content/plugins/` directory.
3. Activate the plugin through the 'Plugins' menu in WordPress.
4. Configure the plugin settings from the admin dashboard.

## Usage
- Navigate to the "Article Performance Management" section in the WordPress admin sidebar.
- Upload a CSV file containing article data (URL, keyword, rank, volume).
- Set the thresholds for ranking and keyword volume in the settings.
- Review the list of articles and their statuses.
- Use the options to unpublish or restore articles as needed.
