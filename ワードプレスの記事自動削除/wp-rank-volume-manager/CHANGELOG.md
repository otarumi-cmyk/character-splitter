# Changelog

## [Unreleased]
### Added
- Initial plugin structure and files.
- Basic functionality for managing article visibility based on rank and volume.

## [1.0.0] - 2023-10-01
### Added
- Implemented CSV import functionality for article data.
- Created admin dashboard to display article performance metrics.
- Added settings page for configuring thresholds and rules.
- Developed logic for determining which articles to unpublish based on user-defined criteria.
- Implemented restoration feature for unpublished articles.

## [1.0.1] - 2023-10-15
### Fixed
- Resolved issues with CSV parsing and data validation.
- Improved error handling during the import process.

## [1.1.0] - 2023-11-01
### Added
- Introduced logging functionality to track changes and actions taken by the plugin.
- Enhanced user interface for the admin dashboard with better visual indicators.

## [1.1.1] - 2023-11-15
### Fixed
- Fixed bugs related to the restoration of articles to their original status.
- Improved performance during bulk operations.

## [1.2.0] - 2023-12-01
### Added
- Added support for excluding specific categories and tags from being unpublished.
- Implemented a history tracking feature to log all changes made by the plugin.

## [1.2.1] - 2023-12-15
### Fixed
- Addressed minor UI issues in the settings and dashboard views.
- Fixed compatibility issues with the latest version of WordPress.

## [1.3.0] - 2024-01-01
### Added
- Introduced a feature for bulk restoration of unpublished articles.
- Enhanced the settings page with additional configuration options.

## [1.3.1] - 2024-01-15
### Fixed
- Fixed issues with the display of historical data in the dashboard.
- Improved overall plugin stability and performance.
